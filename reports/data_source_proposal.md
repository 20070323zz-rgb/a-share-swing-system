# 数据源备用方案 Proposal 2026-06-03

本报告只讨论公开行情数据和手动数据导入，不包含任何券商交易接口、真实下单、账号密码、验证码、token、融资融券、杠杆或自动交易功能。

## 当前问题

当前 AKShare / 东方财富公开行情源在部分网络环境下不稳定，表现包括：

- `ProxyError`
- `RemoteDisconnected`
- `ConnectionError`
- `NameResolutionError`
- 单标的慢速下载仍失败
- 原始 AKShare 接口也可能失败

这说明问题不在字段映射、`watchlist.csv` 读取、`enabled/type/source` 判断，而集中在公开行情源访问稳定性。

## 当前可继续使用的部分

- 已有合格本地 CSV 仍可继续使用。
- 当前缓存数据不会因为当天下载失败而被删除。
- 如果 `data/<code>.csv` 合格，日报、回测和 `model_dataset.csv` 仍可继续使用该标的。
- 如果某标的下载失败且本地无 CSV，会在日报中显示 `NO_DATA`，并不会阻塞系统运行。

## 备用方案 A：手动导出 CSV

方式：

- 从东方财富、同花顺、Choice、券商软件或其他行情软件手动导出日线 CSV。
- 放入 `raw/`。
- 用 `scripts/normalize_csv.py` 标准化为 `data/<code>.csv`。

优点：

- 最安全，完全不需要账号接入本系统。
- 不依赖 AKShare 当天接口是否稳定。
- 可以先补最关键 ETF，例如宽基和行业 ETF。
- 与现有模拟盘、回测、报告逻辑完全兼容。

缺点：

- 需要人工下载。
- 数据更新频率依赖人工操作。
- 不同软件导出的字段格式可能不同，需要先标准化。

当前优先级：最高。

## 备用方案 B：BaoStock

方式：

- 使用 BaoStock 作为免费备用行情源。
- 只用于历史行情下载。
- 不接交易接口，不下单。

优点：

- 免费。
- 相对适合 A 股股票和部分指数数据。
- 可作为 AKShare 之外的公开数据兜底。

缺点：

- ETF 覆盖和字段质量需要实际测试。
- 需要额外代码适配和数据质量检查。
- 稳定性仍需观察。

当前优先级：中等，建议等手动 CSV 导入流程跑通后再评估。

## 备用方案 C：Tushare Pro

方式：

- 使用 Tushare Pro 获取行情数据。
- 需要 token。
- 本项目只允许把 token 用于行情数据，不允许用于任何交易功能。

优点：

- 数据体系更完整。
- 稳定性通常比临时网页接口更好。
- 后续可扩展财务、指数、行业等研究数据。

缺点：

- 需要 token，必须谨慎管理。
- 可能需要积分或权限。
- 需要额外配置，不应把 token 写入代码或提交到仓库。

当前优先级：中等偏后。等手动 CSV 和 BaoStock 评估后，再决定是否引入。

## 推荐路线

1. 先做手动 CSV 导入，把关键 ETF 的 `data/*.csv` 补齐。
2. 对失败行业 ETF，优先用 `raw/` + `scripts/normalize_csv.py` 导入。
3. 等模拟盘报告稳定后，再评估 BaoStock。
4. 如果确实需要更稳定的数据源，再讨论 Tushare Pro，只做行情，不做交易。

## 安全边界

- 不接券商 API。
- 不真实下单。
- 不读取、保存、传输账号密码、验证码或交易 token。
- 不做融资融券、杠杆或自动交易。
- 只做公开行情下载、手动数据导入、模拟盘、回测和报告。
