# 研究工作流与 AI 协作

[返回项目首页](../../README.md) · [项目研究路径](research-overview.md)

项目使用 ChatGPT / Codex 协助编写代码、生成检查工具、组织研究材料和整理文档。公开展示依据保存的报告及数值摘要，不将整个工程表述为个人独立编写。

## 工作如何记录

研究问题、样本、规则、比较对象和评价范围通过任务约定与冻结文件记录；实现后用逐日 / 逐单核对、定向检查和结果比较形成证据；后续工作引用既有记录，保留不支持假设的判断。

AI 生成代码或文档不等于结果正确，也不等于研究者已独立掌握相关方法。代码规模、报告数量与工程测试数应与个人能力分别理解。

## 个人贡献怎样说明

本次先发布项目层面的工作与证据。个人亲手实现、能够独立解释的方法和实际核查范围，将依据实际经历另行补充。目前不作“独立开发整个系统”或“独立完成全部统计分析”的声明。

后续贡献说明应具体对应选题、数据处理、比较设计、结果核对和实现，并与 AI 协助部分区分。未独立完成或暂未掌握的内容保留原状，不由文档代为补足。
