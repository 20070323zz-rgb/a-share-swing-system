# 关键术语解释

[返回项目首页](../../README.md) · [主研究案例](daily-vs-weekly.md) · [代码阅读导航](code-reading.md)

本页按当前三 ETF 案例解释术语。文档更新：2026-10-05；研究结果与样本范围保持原报告约定。

## 研究对象与信号

| 术语 | 含义 | 在本案例中怎样使用 |
| --- | --- | --- |
| Universe（研究集合） | 实验允许选择的标的集合 | 固定为 510300、510500、159915 三只 ETF |
| 动量 / TR20 | 最近一段时间的回报，用来比较相对强弱 | 总回报指数在检查日与 20 个实际交易观察日前的比值减 1，需 21 个有效观察 |
| Top2 | 按规则排序后的前两名 | 分数降序、ETF 代码升序解并列；全部为负仍选择两只 |
| Daily / Weekly | 检查目标组合的频率 | 每个实际交易日 / 每周最后实际交易日；检查不等于一定成交 |
| 总回报指数 TR_INDEX | 按约定纳入现金分红与份额变动影响的回报序列 | 用于生成动量信号；模拟账户的成交、估值和分红现金另外处理 |
| raw open / raw close | 原始开盘价 / 原始收盘价 | 下一实际交易日开盘价用于成交，收盘价或经核验的参考用于估值 |

## 交易与结果

| 术语 | 含义 | 阅读提示 |
| --- | --- | --- |
| 交易摩擦 | 成交时产生的费用或价格差异 | 本案例计入假设佣金和滑点；最低佣金、份额单位及现金约束也影响账户路径 |
| 滑点 | 成交价格相对参考价格的偏移 | 冻结规则中买入价高于原始开盘价，卖出价低于原始开盘价 |
| 研究权益 | 按约定计算的账户总价值 | 可用现金、待可用分红现金、应收及持仓估值的合计；买入只能用可用现金 |
| 最大回撤 MDD | 权益相对此前最高点的最大下降幅度 | 权益曾为 100 后降至 60，对应回撤 −40%；不同于累计净收益 |
| 基点 bps | 百分点的百分之一 | 1 bps = 0.01 个百分点，100 bps = 1 个百分点 |

例如，31.77 bps = 0.3177 个百分点。本项目中的 −31.77 bps 是两类区间的**净局部效果中位差**，不是完整 Daily / Weekly 账户累计收益之差。

## 机制与验证

| 术语 | 含义 | 本案例的解释范围 |
| --- | --- | --- |
| whipsaw（周内目标反复） | 目标集合变化后，又返回此前的集合 | 如 A→B→A；一个完整周区间只要出现这类返回，就按冻结分类记为 whipsaw |
| 局部反事实 | 从同一个账户起点比较几种不同处理方式 | 每个区间复制实际动态、保持持仓及同数量无摩擦三分支；分红、份额变动及估值继续处理 |
| 区块自助抽样 | 把相邻观察组成区块，再有放回地抽取，生成重采样结果 | 预定为 8 个完整区间一块、10,000 次；用于检查原样本内统计结构 |
| 逐一区间移除 LOO | 每次去掉一个区间，重新计算同一统计量 | 检查结果是否明显依赖单个区间；本案例移除 278 个有变化区间各一次 |
| 样本内 / 前瞻样本外 OOS | 已用于研究的历史样本 / 规则冻结后按协议收集的新观察 | 原历史检查不等于前瞻验证；冻结前已经接触的数据不能补记为前瞻观察 |
| 合成测试 | 使用专门构造的输入验证程序行为 | 检查账务、时点、取消订单、不重复执行及恢复，不产生真实投资表现 |

### A→B→A 的小例子

假设周区间起点的目标 A 为 `{510300, 510500}`，随后变成 B `{510300, 159915}`，又回到 A。这说明目标在区间内发生反复；实际是否成交、成交数量和成本仍取决于下一交易日执行及现金约束。

### 为什么局部效果不能相加当作整段收益差

每个局部区间都从该区间的 Daily 实际完整状态重新开始。它比较的是“在这个共同起点下，周内操作发生了什么”。这些分支不连续复利连接成一个新的全程账户，因此各区间局部总量不能作为完整 Weekly−Daily 终值差的分解。
