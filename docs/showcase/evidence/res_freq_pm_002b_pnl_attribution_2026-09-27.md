## 三分支与核对

每个区间从同一 Daily Base 实际账户完整状态复制：可用现金、待可用现金、应收、ETF 份额、企业行动、已冻结分红权益、估值最近标记和账户目标状态。`DAILY_DYNAMIC_BASE` 重放冻结 Daily 订单；`HOLD_BASE` 不执行任何周内信号订单；`DAILY_DYNAMIC_FRICTIONLESS_SHADOW` 逐笔复制实际成交日期、ETF、方向与**完全相同的成交数量**，但按 raw open 且佣金/滑点为零。实际取消的零成交订单在影子分支仍为零成交。

起点在下一个实际交易日收盘，终点在下一 Weekly checkpoint 收盘估值后、其新信号订单执行前。三个分支各自照常处理分红登记、应收与释放、2015/2022 份额变动以及停牌/官方参考估值。实际分支在每个重放日的订单、持仓、现金、应收、估值和权益都与 TR-003 Daily Base 逐项一致；2015-04-15 无效信号保持。每个区间的完整起始状态和三个分支的相同哈希保存在 `common_start_states.jsonl`。

区间效果定义为：`净 = 实际动态终值 − 持有终值`；`摩擦前路径 = 无摩擦动态终值 − 持有终值`；`摩擦 = 实际动态终值 − 无摩擦动态终值`。687 个区间逐一**精确**满足 `净 = 路径 + 摩擦`。bps 的分母为该区间共同起点的研究权益。无 Daily 目标变化的 **409** 个区间，实际与持有分支逐日相同；有变化 **278** 个，其中 whipsaw **111** 个。
