## 口径与完整性

研究 Universe 固定为 510300、510500、159915；2013-04-19 至 2026-09-15。每个合法 Daily 信号保留三只连续分数、完整 Rank1/2/3 及 `Rank2 − Rank3` 原始差值。所有 3,260 个 Daily 检查日均映射到实际交易日周区间；其中 4 个无效日不进入 gap 统计或目标事件，2015-04-15 继续无效。目标变化的 461 个信号日期与 TR-003 Base 订单来源日期完全相同，Weekly 的 205 个也完全相同；Base 与 Stress 两组目标时间线一致。

完整周区间采用 `(上一个合法 Weekly checkpoint, 下一个合法 Weekly checkpoint]` 的不重叠交易日分配。第一个 checkpoint 是首次建仓锚点；最后两天所属未完结周另存 `TRAILING_CENSORED`，不计入完整周区间比率。首次建仓计入 461 个 Daily 目标事件和首个区间的 rebalance count，但不算周内 target change 或 whipsaw。Weekly checkpoint 由真实交易日历决定。

## 额外订单与假设成本

按信号日所属 Weekly interval，把 Daily 和 Weekly 的已成交订单依次做一对一配对；配对键同时要求旧→新 Top2 变化、ETF 和买卖方向相同，不要求份额数量相同。Daily 的 **1015** 笔已成交订单中，**607** 笔未找到对应 Weekly 形态。它们的佣金加滑点合计 **4,970.12 CNY**。

Daily 与 Weekly 的假设总成本净差为 **4,327.78 CNY**；额外订单成本 / 净差为 **114.84%**。该比例超过 100% 是因为 Weekly 自身及其余已配对订单仍有成本，净差会相互抵消。它是订单层成本描述，**不是**最终权益差或收益差的因果分解。
