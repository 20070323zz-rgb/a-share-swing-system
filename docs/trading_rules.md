# 交易规则文档

本文件记录项目层面的交易研究规则。规则只用于模拟盘和研究约束，不代表真实交易指令。

## 标的范围与个股仓位上限

1. 本项目主要交易对象应以宽基指数 ETF 和行业 ETF 为主。
2. 个股只作为观察、学习和小比例验证对象，不作为系统主仓来源。
3. 无论中期仓还是短期仓，所有个股合计仓位不得超过账户总仓位的 10%。
4. 这里的 10% 是“全部个股合计上限”，不是单只个股上限。
5. 即使个股信号很强，或出现主观看涨、热点题材、短期机会判断，也不得突破 10% 总上限。
6. 若未来需要提高个股仓位上限，必须先回到 Rule 对话重新讨论并确认，不允许在 Main 或代码层面直接修改。
7. 保持项目安全边界不变：
   - 不接入券商接口；
   - 不真实下单；
   - 不保存账户信息；
   - 不实现自动交易。
